# 祖源计算器（Admix Container）

版本：**v1.0.81**

放进计算器包（DIYDodecad 风格 `.zip`，如 E11 / K47）和原始基因型数据，在浏览器本地跑出祖源成分比例。**所有计算都在本机浏览器内完成，文件不上传、不经过服务器。** 单文件自包含，图标已内联，无外部资源依赖。

## 目录结构

```
admix-container/
├── index.html              # 单文件应用入口（HTML + CSS + JS + 图标全部内联）
├── .nojekyll               # 禁止 Jekyll 处理，保证静态资源原样发布
└── README.md
```

## 支持的输入

- 计算器包：DIYDodecad 风格 `.zip`（频率矩阵 `*.[K].F/.P`、等位基因 `*.alleles`、成分名 `*.txt`/`*.pop`，可带 `*.par` 索引），如 E11、K47、K8、K12、LH6。
- 原始数据：PLINK `.bed+.bim+.fam` / `.ped+.map`、EIGENSTRAT `.geno+.snp+.ind`、23andMe / WeGene `.txt`、VCF（含 `.vcf.gz`），支持打包成 `.zip` 批量导入。

## 本地预览

直接用浏览器打开 `index.html` 即可；如需本地静态服务器：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

## 上架 GitHub Pages

1. 在 GitHub 新建一个**公开**仓库（私有仓库需要 Pro 套餐才能用 Pages），例如 `admix-container`。
2. 把 `index.html`、`.nojekyll`、`README.md` 上传到仓库根目录，分支用 `main`。本版本无 `assets/` 目录，图标已内联进 HTML。
3. 仓库 **Settings → Pages**：
   - **Source** 选 `Deploy from a branch`；
   - **Branch** 选 `main`，目录选 `/ (root)`，保存。
4. 等待 1–10 分钟，访问：

   ```
   https://<你的用户名>.github.io/<仓库名>/
   ```

5. （可选）把 `index.html` 里 `<meta property="og:url">` 的占位地址 `https://YOUR_USERNAME.github.io/YOUR_REPO/` 改成上面的实际地址。

### 后续更新

替换仓库根目录的 `index.html` 后提交即可，Pages 会自动重新发布；版本号在页面标题、右上角标签、页脚和诊断内置常量四处保持一致。

## 界面与压测说明（v1.0.81）

- 计算器包解析：以频率矩阵 `*.[K].F/.P` 为锚点，自动配对 `.par` 指定的等位基因与名单文件；支持 `.pop` 名单与 `.par` 索引（DIYDodecad 打包格式）。
- 分组标签：读取 PLINK（`.fam/.ped/.tfam` 的 FID）、EIGENSTRAT（`.ind` 第三列人群）、CSV（长表分组列 / 宽表表头拆分）后自动识别样本分组，结果标题、PNG 与导出 Excel 统一显示为「分组名:个体名」；无分组时退回个体名。
- 导出 Excel：按「数据批次 × 计算器」分工作表，每个组合一张成分比例主表 + 一张覆盖率明细表，各自冻结首行并默认开启独立筛选，说明页不挂冻结/筛选；结果表标杆（成分）名不带 `%`，`%` 只标注在下方成分数值上；列宽按表头与单元格文字长度自适应（中文/全角按 2.1 字符宽折算，表头加粗略宽），说明段落自动换行。表名超 31 字符时优先保住计算器名、只裁批次标签，主表/明细表与同批次多计算器之间不撞名。
- 覆盖率详情惰性挂载：默认收起的卡片不在首屏渲染覆盖率明细子树，首展开时才插入；初始 DOM 节点约下降 40%，批量铺卡与视图切换/搜索重渲染更快，已展开卡片的明细在切换视图后保留。
- 底部「故障诊断与自动抓包」面板与其他折叠区统一：max-height 高度过渡、箭头 90° 旋转、内容淡入；报错自动展开也走同一套折叠动画，不再瞬间显隐。
- 「使用手册」「背景色」两个折叠面板补齐内层内容淡入，与模板、诊断面板的展开/收起动效保持一致。
- 饼图为正圆：大于 50% 的扇形按优弧绘制；成分按比例降序排列。
- 每条引线为单段直线，从本扇形中位角的饼边引出，直指外侧标签色点；标签整圈等角环绕，块—引线—标签一一对应，不穿饼、不交叉、不重叠。名称与百分比分列两行，下方图例保留完整成分名与数值。
- 中端安卓等效环境（CPU 4× 节流）批量计算：全部任务成功、无失败、无零命中，无页面报错、无横向溢出；交互阶段（滚动、切换视图、展开详情、搜索）无掉帧。
- 计算阶段偶发百毫秒级主线程停顿（结果回传后批量刷新卡片时）；一次性数据解压/解码阶段有秒级主线程占用，属正常载入开销。
- 浏览器内存有限，超大批量样本请分批导入；结果可导出 Excel。

## 常见问题

- **诊断包里版本号显示旧版**：确认仓库根目录的 `index.html` 是最新构建；页脚、右上角标签、诊断内置版本号应一致。
- `.nojekyll` 是点开头的隐藏文件，部分手机解压工具会默认隐藏或跳过，但它在压缩包内。
- 纯静态页面，无后端、无数据库、无账号体系。
- 成分比例为固定参考面板下的监督式混合估计，仅作祖源参考。
