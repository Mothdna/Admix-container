祖源计算器 v1.0.72

放进计算器.ZIP和原始数据，
在浏览器上跑出祖源比例。

支持 E11、K47 等 DIYDodecad 格式的计算器压缩包，搭配 23andMe / WeGene 原始 txt。解压、位点匹配、混合比例估计全部在这台设备完成，文件不会上传。

使用手册

  • 板块一放计算器一个或多个 .zip，每个 zip 里含完整计算器：*.[K].F 或 *.[K].P 频率矩阵、*.alleles（rsid + 两个等位基因），名单 *.txt / *.pop 可选；也支持带 *.par 的 DIYDodecad 包。
  • 板块二放样本23andMe/微基因 txt、通用「位点+基因型」txt、CSV/TSV（含 HapMap 的 .hapmap/.hmp/.hmp.txt 矩阵）、VCF 与 .vcf.gz、PLINK bed/bim/fam 或 ped/map、EIGENSTRAT 三件套，或把这些打包成 zip。含多样本的文件会拆成每个样本一条结果。
  • 开始计算线程按设备自动分配：桌面取核数−1（最多 12），iPhone 2，其他手机最多 4。想中途停下点「先用当前结果出图」，已完成的条目会保留。
  • 先看覆盖率每张卡上半是比例，下半是覆盖率详情。默认文字视图，点「饼图」切换。覆盖率很低（如 10%–20%）时，比例只能作粗参考，不是算错。
  • 导出 Excel导出按计算器分工作表，另附说明页；只写入已完成的结果。
  • 按位置匹配（不用 rs 号）如果原始数据的位点编号是芯片内部编号（a012904 这类）、或编号体系和计算器不一致，只要在板块二载入一次参考序列模板即可，程序会改用「染色体:位置」对齐位点，不再依赖 rs 号。不需要为每个计算器单独准备坐标表；计算器包里自带的坐标表仍然优先使用。
  • 已知限制zip 内单条目超过 160MB 会跳过（可在电脑解压后直接选散文件）；宽表 CSV 最多 64 个样本列；只有 0/1/2 编码而无 A/B 等位基因说明的矩阵不支持；同名样本自动加序号保留，不会丢。
